Gerador de Senhas usando HTML e CSS, com um visual moderno, fundo escuro e detalhes em verde. Como você está aprendendo desenvolvimento web, vamos separar o projeto em arquivos para facilitar o estudo.

O site terá:
- Campo para exibir a senha gerada.
- Botão para copiar a senha.
- Opção de escolher o tamanho da senha.
- Opções para incluir letras maiúsculas, minúsculas, números e símbolos.
Observação: para gerar e copiar senhas, também precisamos de um pouco de JavaScript, além do HTML e CSS.
